# 教师课程改革证据台

整理教师培养方案、实践证据和持续发展之间的关系，为培养方案评审提供**证据缺口图**，而不是一张"已经开设AI课程"的完成表。

## 领域资料

仓库中的 `contracts/` 描述资料格式，`fixtures/` 给出可公开使用的虚构示例。代码库只负责读取、校验与评估这些资料，业务服务可沿用相同标识和版本约定（每份资料均带 `domain` + `version` 信封）。

当前资料反映的事实包括：

- 课程改革需回应AI时代知识边界
- 职前培养与持续发展需要衔接
- 国际比较涉及不同制度环境

## 资料与模块

| 资料（contracts/ + fixtures/） | 内容 | 评估模块（src/） |
| --- | --- | --- |
| `competencies` | 培养目标及其知识/实践证据要求 | `gaps.js` 证据缺口评估 |
| `programs` | 历次培养方案：学分规则、独立设课或融入的选择、并轨规则 | `credits.js` 补修判定 |
| `courses` | 校内课程目录 | `pathways.js` 真实路径 |
| `evidence` | 课程记录、工具演示、实习任务、导师观察、毕业后研修 | `board.js` 按届证据台 |
| `comparisons` | 十国比较维度、本地制度背景、国外案例的借鉴条件 | `compare.js` 借鉴评估 |
| `roles` | 角色范围：权限、隐私级别、届别与阶段范围 | `access.js` 授权与过滤 |

## 业务规则

- **多项材料共同证明**：一项能力可要求多份材料、多种类型共同支撑（如实践通道要求实习任务与导师观察两类）。
- **工具演示不冒充实践**：`tool_demo` 可支撑知识通道，但永远不计入实践达成；若被拿来冒充，会被显式拦下并记录在 `tool_demo_rejected`。
- **补修按届判定**：学分规则变化只影响被并轨规则覆盖的届别（示例中为2022届），其余老生老办法。
- **借鉴看制度背景**：国外案例声明其制度条件，全部满足才可借鉴，关键条件不满足则不可借鉴。
- **权限与隐私**：评审动作逐项核对角色权限、隐私级别、届别与阶段范围；越权一律拒绝并留痕。学生引用必须匿名化（`stu-anon-` 前缀）。
- **按届查看**：`buildCohortBoard(cohort, data, session)` 输出该届的改革影响、各能力缺口状态、未补齐或已由入职研修补齐的证据、补修要求与路径完整性；`session` 可选，用于按角色过滤证据引用。

## 本地校验

运行项目自带测试即可确认样例资料可读取、领域标识与版本字段完整、上述业务规则成立：

```sh
npm test
```

所有示例均为虚构数据，不含真实个人信息、账号或访问凭据。
